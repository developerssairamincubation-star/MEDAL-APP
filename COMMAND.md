## 1. 🐳 Docker & MinIO Storage

MinIO provides on-premise S3-compatible evidence storage.

```powershell
# Start MinIO in background
docker compose up -d

# Check running status
docker compose ps

# View live MinIO logs
docker compose logs -f minio

# Stop MinIO container
docker compose down

# Restart MinIO
docker compose restart
```

* **MinIO API Endpoint:** `http://localhost:9000`
* **MinIO Web Console:** `http://localhost:9001` (User: `minioadmin`, Pass: `minioadminpassword`)
* **Bucket Name:** `medal-evidence`

## 2. 🐍 Backend & Python Environment

All backend commands run inside the `backend` directory using its dedicated virtual environment.


## 3. 🐘 Database & Alembic Migrations

MEDAL uses PostgreSQL with SQLAlchemy ORM and Alembic migrations.

```powershell
cd E:\MEDAL\MEDAL-APP-main\backend
.\venv\Scripts\activate

# Apply all pending database migrations to latest version
alembic upgrade head

# Check current migration revision
alembic current

# View complete migration history
alembic history --verbose

# Create an autogenerated migration after editing models
alembic revision --autogenerate -m "describe_changes_here"

# Rollback the last applied migration
alembic downgrade -1

# Rollback to base (empty database)
alembic downgrade base
```

## 4. ⚡ FastAPI Server Execution

```powershell
cd E:\MEDAL\MEDAL-APP-main\backend
.\venv\Scripts\activate

# Run development server with auto-reload (binds to all interfaces for LAN access)
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# Run with custom log level
uvicorn main:app --host 0.0.0.0 --port 8000 --reload --log-level info

# Run multi-worker production instance
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
```

* **Swagger OpenAPI Docs:** `http://localhost:8000/docs`
* **ReDoc Documentation:** `http://localhost:8000/redoc`
* **Connectivity Health Check:** `http://localhost:8000/health`

## 6. 📱 Flutter Mobile Application

All Flutter commands run inside the `frontend/medal` directory.

```powershell
# Navigate to Flutter project
cd E:\MEDAL\MEDAL-APP-main\frontend\medal

# 1. Fetch dependencies
flutter pub get

# 2. Clean build cache (if encountering build/gradle sync issues)
flutter clean
flutter pub get

# 3. Run static analysis (verify zero errors/warnings)
flutter analyze

# 4. List connected devices (Physical phones, Emulators, Chrome)
flutter devices

# 5. Run on connected device in debug mode
flutter run

# 6. Run targeting a specific device ID
flutter run -d <DEVICE_ID>

# 7. Run on Google Chrome (web mode)
flutter run -d chrome

# 8. Build release APK with custom Gradle cache directory
$env:GRADLE_USER_HOME = "E:\.gradle"
flutter build apk --release --target-platform android-arm64
```

### Hot Keys during `flutter run`:
* `r` — Hot reload (instant UI changes)
* `R` — Hot restart (restarts state)
* `h` — List all available shortcut commands
* `q` — Quit and terminate running app

## 7. 🌐 Wi-Fi & LAN Physical Device Testing

To connect a physical phone to the PC backend over Wi-Fi:

```powershell
# 1. Find your PC's current Wi-Fi IPv4 address
(Get-NetIPAddress -AddressFamily IPv4 -InterfaceAlias "Wi-Fi").IPAddress

# 2. Check if port 8000 is listening and open
netstat -ano | findstr :8000

# 3. Allow port 8000 & 9000 through Windows Defender Firewall (run as Administrator if needed)
netsh advfirewall firewall add rule name="MEDAL FastAPI Port 8000" dir=in action=allow protocol=TCP localport=8000
netsh advfirewall firewall add rule name="MEDAL MinIO Port 9000" dir=in action=allow protocol=TCP localport=9000

# 4. Verify PC health endpoint responds from PowerShell
Invoke-RestMethod -Uri "http://localhost:8000/health"
```

* **Update IP in Flutter**: Edit [`frontend/medal/lib/config/api_config.dart`](file:///e:/MEDAL/MEDAL-APP-main/frontend/medal/lib/config/api_config.dart) and set `kPcWifiIp = '<YOUR_WIFI_IP>';`.
